# 00 Overview

## What It Is

This lab is a runnable conversational graph platform. Conversations are modeled as graph execution, not a flat request-response chatbot.

## Why It Matters

Production agents need routing, memory, tools, retries, handoffs, and resumption. Graphs make those paths explicit.

## Run

```bash
convgraph-lab run-graph --input "Investigate INC-1001 latency"
```

## Extend

Add nodes, edges, conditions, tools, agents, and eval cases together.
