# 06 API, CLI, And Visualization

## CLI

Commands:

- `start-conversation`
- `send-input`
- `resume-conversation`
- `run-graph`
- `visualize-graph`
- `inspect-graph`
- `debug-conversation`
- `run-evals`
- `start-api`

## API

FastAPI exposes conversation start, input, resume, state, history, trace, debug report, graph execution, graph inspection, visualization, and eval endpoints.

## Visualization

Exports:

- Mermaid
- Graphviz DOT
- JSON graph view

Execution traces can mark visited nodes.
