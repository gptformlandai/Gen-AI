# Workflows

## What It Is

Deterministic workflow modules for sequential investigation, parallel fan-out, loop refinement, routing, approval simulation, and escalation.

## Where It Appears

- `workflows/sequential_investigation.py`
- `workflows/parallel_diagnostics.py`
- `workflows/loop_refinement.py`
- `workflows/router_workflow.py`
- `workflows/human_approval.py`
- `workflows/escalation_checker.py`

## Why It Matters

Long-running operational workflows need explicit paths, not only model instructions.

## Extend It

Add graph routes and resume checkpoints for long-lived production investigations.
