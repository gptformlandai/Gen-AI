# Risk Register

| Risk | Impact | Mitigation |
|---|---|---|
| Wrong retrieval | Bad remediation | RAG grounding evals and citations |
| Unsafe tool call | Production incident | Tool guardrails and approval |
| Sensitive data leak | Compliance issue | Redaction and output checks |
| MCP timeout | Partial diagnosis | Timeout handling and fallback |
| Memory pollution | Bad future recommendations | Memory summarization and review |
| Overfitted evals | False confidence | Held-out and adversarial tests |
