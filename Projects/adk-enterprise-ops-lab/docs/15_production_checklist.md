# Production Checklist

- [ ] Real ADK agent deployment path tested.
- [ ] Cloud auth configured with least privilege.
- [ ] Secrets loaded from Secret Manager.
- [ ] MCP tools have timeout and retry policy.
- [ ] Mutating tools require human approval.
- [ ] RAG corpus has freshness and ownership metadata.
- [ ] Eval gate runs in CI before deployment.
- [ ] Traces exported to OpenTelemetry.
- [ ] Artifacts stored in GCS with retention policy.
- [ ] Memory backend has deletion and privacy controls.
- [ ] Guardrails include adversarial tests.
- [ ] Runbook for operational troubleshooting exists.
