# Extension Guide

## Add Agent

Create prompt, agent module, factory registration, runner route, and eval case.

## Add Tool

Create typed function, normalize result, register metadata, add guardrails, test.

## Add RAG Source

Add loader, chunker settings, retrieval evals, and source metadata.

## Add MCP Server

Add MCP toolset config, client wrapper, timeout policy, and error handling tests.

## Add Memory Backend

Replace `InMemoryMemoryService` with persistent storage while preserving `add`, `search`, and `summarize`.
