# Overview

## What It Is

`adk-enterprise-ops-lab` is a production-style Google ADK reference backend for enterprise incident investigation.

## Where It Appears

- Runtime: `src/enterprise_ops_lab/runner.py`
- Agents: `src/enterprise_ops_lab/agents/`
- Tools: `src/enterprise_ops_lab/tools/`
- Evals: `src/enterprise_ops_lab/evals/`

## Why It Matters

It demonstrates how ADK concepts fit into one cohesive system instead of isolated snippets.

## Extend It

Start with a new tool, then add a specialist agent, then add an evaluation case.
