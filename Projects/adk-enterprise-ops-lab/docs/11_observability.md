# Observability

## What It Is

Structured logs, local trace files, tool call logs, workflow step logs, error categories, and metrics placeholders.

## Where It Appears

- `observability/logger.py`
- `observability/tracing.py`
- `observability/metrics.py`
- `.traces/`

## Why It Matters

You cannot debug agent behavior from the final answer alone.

## Extend It

Send trace events to OpenTelemetry, Cloud Logging, and Cloud Trace.
