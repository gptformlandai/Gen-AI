# Project 3: Baseline RAG Assistant With Citations

This project implements a baseline Retrieval-Augmented Generation assistant over a generated support knowledge-base corpus.

The assistant answers only from retrieved evidence and returns citations. If the retrieved evidence is weak, it refuses instead of guessing.

## Project Requirements Coverage

| Spec requirement | How this project handles it |
|---|---|
| Ingestion and chunking strategy | `corpus.py` loads JSONL documents and `chunking.py` creates overlapping chunks. |
| Vector retrieval over corpus | `vector_store.py` performs cosine search over local embeddings. |
| Prompting separates evidence from final answer | `prompts.py` has an evidence packet and answer contract. |
| Citation output with source traceability | `rag.py` returns citation IDs, document IDs, chunk IDs, titles, quotes, scores, and metadata. |
| 20 to 25 evaluation questions | `data/evaluation_questions.json` contains 22 questions. |
| Basic trace or logging mechanism | `tracing.py` writes JSONL trace events for retrieval, evidence, and answer decisions. |

## Architecture

```text
user question
    |
    v
embed question
    |
    v
retrieve top-k chunks
    |
    v
build evidence packet with source IDs
    |
    v
synthesize answer from evidence only
    |
    +--> answered with citations
    |
    +--> refused when evidence is insufficient
```

## What This Recalls From The Modules

- **Module 6: RAG foundations** - the model should answer from retrieved context, not memory.
- **Module 8: Evaluation and observability** - RAG quality is measured with labeled questions, pass/fail outcomes, and failure categories.
- **Project 2 connection** - retrieval ranking is reused as a subsystem, but Project 3 adds grounding, citation traceability, and refusal behavior.

## Run Locally

```bash
cd Projects/project-3-baseline-rag-assistant
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

Generate the corpus:

```bash
baseline-rag build-corpus --output data/corpus.jsonl --count 240
```

Ask a question:

```bash
baseline-rag ask \
  --corpus data/corpus.jsonl \
  --question "How do users reset a forgotten password?"
```

Run evaluation:

```bash
baseline-rag evaluate \
  --corpus data/corpus.jsonl \
  --questions data/evaluation_questions.json \
  --output docs/evaluation_sheet.md
```

## Tests

```bash
cd Projects/project-3-baseline-rag-assistant
pytest
```

The baseline is deterministic and does not require an API key. A later version can replace the extractive answer synthesizer with an LLM call while keeping the same evidence packet, citation schema, and evaluation harness.
